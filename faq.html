FAQ

常见问题

关于数据来源、倍率口径、安全性和排名的常见疑问。

AI API 中转站安全吗？

中转站能看到经过它转发的请求。不要提交密码、身份证件、私有代码或生产数据。正式业务优先使用厂商官方 API。

为什么有的站点倍率很低却不能直接比较？

不同站点给出的倍率口径不同。只有分组倍率、没有公开充值系数的，无法折算成相对官方价的倍率，本站只显示原值，不参与排名。看倍率计算方法。

本站的价格数据从哪里来？

来自站点公开价格接口、官网价格页、用户提交与截图。每条报价都有来源链接和核验日期，用户截图类会标待核验。详见 核验方法。

综合倍率 1.00x 是什么意思？

1.00x 表示站点价格等于厂商官方价。0.10x 表示官方价的一折，数值越低越便宜。

免费中转站有什么风险？

免费额度可能来自号池或限速线路，存在数据可见、模型掺水、限流排队和随时关站的风险。不要用免费通道处理敏感数据。看风险说明。

怎么判断中转站宣称的模型是真的？

用小额请求多次测试，核对响应里的模型标识与用量字段，对比官方价和响应质量。本站目前记录价格与来源，不做 API 真实调用验证。

本站的排名可以付费提升吗？

不可以。排序只按口径统一的综合倍率，推广链接会标注，但不影响名次。

发现价格错误怎么办？

在 GitHub 仓库提交 Issue，附上来源链接和日期，核验后会更新对应报价。
