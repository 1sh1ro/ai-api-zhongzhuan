# 人气榜口径

人气榜统计的是读者从本站点击出去、进入某个中转站的次数，不是该站自己的注册量或真实用户量。

## 计数方式

- 数据存在公开的第三方计数器 [Abacus](https://abacus.jasoncameron.dev)，命名空间 `ai-xulas-fun`。
- 键名：当月 `click-{stationId}-{YYYY-MM}`，当日 `click-{stationId}-{YYYY-MM-DD}`。日期按亚洲/上海时区。
- 同一浏览器（localStorage）每天对同一站点只上报一次，用来降低刷点击。这不是登录身份去重，清缓存或换设备仍可再计一次。
- 构建页面时用 `GET /get/...` 拉取快照，写入 `data/popularity-snapshot.json`，并预渲染到 `/popular/`。浏览器打开页面后会再读一次当月计数。
- 进入正式排名的最低样本是当月 3 次去重点击。未达阈值的站点仍列在表里，但不编排名次。还没有计数记录的站点显示「积累中」，不用估计值填榜。

## 明确不纳入排名的数据

- `data/registrations.json` 是维护者从推广后台手工抄录的注册数；目前为空，榜单不会编造。
- GitHub Issue 的表情或评论不是用户使用量，不计入人气。
- 打开本站的人次不计入各中转站人气。

## 其他规则

- 排名不可以付费提升。带推广参数的注册链接会标明「推广」，但不加分、不减分。
- 人气高不等于价格真实、模型可用或服务稳定。比价仍以各模型的综合倍率和核验日期为准。
