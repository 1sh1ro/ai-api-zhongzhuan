# AI API 导航 GitHub Pages 设计

## 目标

把仓库里的 `data/sites.json` 做成一个可搜索、可筛选的中文静态目录。页面不复制一份易过期的站点数据，而是在浏览器中读取结构化数据；后续维护者更新 JSON 后，页面随 GitHub Pages 一起更新。

## 视觉与信息架构

页面采用深色“夜间控制台 + 编辑部目录”方向：暖白文字、荧光黄操作色、青绿色状态色和细网格背景。首屏给出目录定位、最后核验日期和站点统计；主内容提供搜索、模型标签筛选、状态筛选和排序；卡片展示入口、摘要、标签、核验日期和页面状态；底部固定呈现中转站的隐私与稳定性提示。

## 技术方案

使用根目录 `index.html`、`styles.css`、`app.js`，不引入构建工具。`app.js` 从相对路径 `data/sites.json` 加载数据，适配仓库根目录和 GitHub Pages 项目路径。`.github/workflows/pages.yml` 使用官方 Pages artifact 部署静态文件；现有数据校验工作流继续独立运行。

## 交互与边界

搜索匹配站点名、摘要和标签；“模型”标签按 JSON 的英文 tag 映射为中文；“可访问 / 需核验 / 降级 / 被拦截”保留数据里的状态语义。外部入口使用新标签打开，页面不保存用户输入，也不代理任何 API 请求。加载失败时显示明确错误和仓库数据入口，避免把空列表误认为没有站点。
