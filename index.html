05 / READ FIRST

读之前先看这几条

中转站能看到经它转发的请求

不要提交密码、身份证件、私有代码、生产数据或其他敏感内容，也不要在公开 Issue 里粘贴 API Key。

倍率只是价格，不等于可用

免费额度、倍率、模型覆盖和注册状态随时会变。低价往往对应限流、排队、模型掺水或突然关站。

口径不同的数字不能直接比

站内分组倍率要结合充值系数才能换算成相对官方价的倍率；没有统一口径的条目只作展示，不进入名次。

正式业务优先用官方 API

本页只做公开信息整理，不运营、不担保任何第三方服务，也不鼓励绕过厂商或站点自身的使用规则。
