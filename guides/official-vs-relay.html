GUIDE · 选型

官方 API 和中转站怎么选

按使用场景分，而不是按单价分。生产看稳定和合规，测试看成本和多模型覆盖。

五个维度对比

维度官方 API中转站
价格官方标价常见为官方价的一到几折，口径不一
稳定性有 SLA 和公开状态页无 SLA，限流和关站风险自负
数据厂商直接处理经过第三方，内容可见
合规与发票可对公、可开票多数不可，主体不透明
多模型需要分别开户一个 Key 调多家

生产环境

涉及真实用户数据、付费业务、需要长期稳定和发票时，用官方 API。中转站可以作为降级或备用通道，但不要把唯一入口放在它上面。至少保留一套官方 Key 和可切换的 Base URL。

开发和测试

跑评测、做原型、批量处理、对比多个模型，用中转站能显著降低成本。建议选公开价格页、有明确分组、能查到来源的站点，先小额充值试跑，再决定是否长期用。

成本怎么算才公平

把请求量拆成输入、输出、缓存三部分，分别乘单价，再加上失败重试和限流浪费。只比「输入单价」会低估输出占比较高的任务。可以用 模型官方价索引 作为分母，再看各站的综合倍率。

一个实用组合

开发期用中转站压成本，上线前把关键链路切到官方 API；图片、视频这类固定价任务单独核算。本站的 价格榜 和 站点页 可以帮你快速比较和回溯来源。
