中转站 API 是什么？和官方 API 有什么区别

一句话：中转站是替你去调厂商 API 的中间商，用它的 Key 和余额，按它的倍率计费。

它怎么工作

你拿到的是中转站自己的 API Key 和 Base URL，请求先到中转站，再由中转站转发给 OpenAI、Anthropic、Google 等厂商。中转站统一做鉴权、限流、计费和日志，所以一个 Key 可以调多个模型。

多数站点基于开源的 New API / one-api 搭建，少数是 sub2api 或自研。它们的分组、倍率、额度体系基本沿用同一套概念。

几个必须认识的计费名词

  • 充值系数：充 1 元人民币能换多少站内额度。常见有 ¥1 = $1，也有 ¥1 = $5。
  • 分组倍率：同一个模型分成不同线路，贵的那条通常更稳或走官方 Key。
  • 模型倍率：相对官方价的一个乘数，New API 用它来计算每次调用的扣费。
  • 固定价：图片、视频、语音按张、按秒、按次计价，不按 Token。

和官方 API 的差别

  • 价格：中转站通常低于官方价，代价是来源、稳定性、售后都不透明。
  • 数据：请求会经过第三方，理论上对方能看到内容。不要提交密码、私有代码、生产数据。
  • 模型真实性：有的分组用逆向或号池，宣称的模型和实际返回的模型可能不一致。
  • 稳定性：限流、排队、突然关站都出现过，没有 SLA。
  • 合规：正式业务、对公付款、需要发票时，优先用厂商官方 API。

什么时候适合用

做开发测试、跑批处理、临时对比多个模型、个人副业项目，用中转站能明显压低成本。生产环境、涉及用户数据、需要长期稳定性的场景，建议官方 API 或至少保留可切换的官方通道。
