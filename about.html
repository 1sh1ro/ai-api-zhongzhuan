ABOUT THE INDEX / OPEN SOURCE

先把入口
讲清楚，再决定怎么用。

这是一个公开、可维护的 AI API 公益站与 Token 中转站导航。它把散落在公开页面、社区主题和用户补充里的入口，整理成可以查看来源和核验日期的目录。

DATA FORMATJSON / source-linked
PRIMARY FILEdata/sites.json
MAINTENANCEGitHub / pull request
POSITION入口索引，不是担保
01 / WHYA—01

把“听说有个站”变成一条能回看的记录。

AI API 的入口、倍率和注册状态变化很快。这个目录不试图替任何服务背书，而是把站点链接、摘要、标签、页面状态、核验日期和来源放在同一条记录里，让你在打开之前先知道信息从哪里来、什么时候看过。

网页只是数据文件的一个阅读界面。真正需要维护的是 `data/sites.json`；更新数据后，GitHub Pages 会自动重新发布。

02 / METHODA—02
01

公开入口

优先使用公开首页、注册页、价格页、状态页或公开社区主题作为入口和来源。

02

记录状态

“注册页可达”只表示页面当时能打开；需要人工核验、降级和自动访问受阻会单独标注。

03

留下日期

每条记录保留 `verifiedAt` 和 `sources`。倍率、模型和额度以站点当前页面为准。

03 / USE ITA—03
01

先筛选

按模型、状态或关键词缩小范围，优先看与你的任务相关的入口。

02

再看来源

检查核验日期和来源链接，不把历史快照当成当前承诺。

03

最后小量试用

不要提交敏感信息；正式业务优先使用模型厂商官方 API。

!

04 / BOUNDARY

目录提供线索，不替你承担风险判断。

中转站能够看到经其转发的请求。不要提交密码、身份证件、私有代码、生产数据或其他敏感内容，也不要在公开 Issue 中粘贴 API Key。免费额度、倍率、模型和注册状态随时可能变化。
