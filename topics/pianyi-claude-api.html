常见问题

综合倍率越低就越划算吗？

只说明名义单价更低，不说明可用、不排队、不换模型。低于大约 0.5x、或名称带 Kiro/逆向/号池的，更要先小额实测再决定是否充值。

为什么有的很低价不出现在排名里？

只有口径统一、能折成相对官方价的报价才进入排名。只公布分组倍率、不公开充值系数的，无法公平比较。

本站会为了推广把某站排得更便宜吗？

不会。价格排序只按综合倍率，人气榜只按去重后的出站点击。推广链接会标明，但不影响名次。
