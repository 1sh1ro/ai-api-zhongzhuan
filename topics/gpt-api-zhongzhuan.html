常见问题

GPT API 中转能替代官方 API 吗？

开发测试和批处理可以明显降低成本。生产环境、用户数据或需要发票时，仍建议官方 API，或至少保留可切换的官方通道。

为什么同一站点会有好几档 GPT 价格？

不同分组对应不同线路或上游，便宜的分组往往限制更多。请看分组名、来源和核验日期，不要只记一个最低数字。

怎么确认中转出来的真是该型号？

本站目前只记录公开价格和来源，不做真实调用验真。需要自己用小额请求核对模型标识、用量字段和输出质量。
