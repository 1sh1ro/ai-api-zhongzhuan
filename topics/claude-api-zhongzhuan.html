常见问题

Claude API 中转和官方 API 有什么差别？

官方 API 由 Anthropic 直接计费和提供服务。中转站是中间商，用它自己的上游和余额，按它的倍率扣费。正式业务、涉及用户数据或需要发票时，优先用官方 API。

为什么有的 Claude 中转看起来特别便宜？

有的分组走号池、逆向或限速线路，标价可以远低于官方价。低倍率不等于模型真实或稳定。本页会把分组名中带 Kiro、逆向、号池或 CC Max 的条目标出来，并保留核验日期。

本页的数字会过期吗？

会。中转站价格、分组和上游经常变动。请以各条报价的核验日期为准，充值前到站点价格页复核，并先小额测试。
